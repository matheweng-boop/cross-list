{%- endmacro %} {# One definition of the cross types, used on the home page and the rules page #} {% macro cross_type_definitions() -%}
  • Drop-in (FFF) – same package and pin-to-pin, and every priority 1 parameter equal or better (better ones are marked). Priority 2 and 3 differences are listed for review.
  • Functional equivalent – different package or pinout; priority 1 equal or better apart from at most 2 deviations (adjustable 0–3 on the part page).
  • Package equivalent – same package and basic function, different technical specification; marked pin-to-pin or not.

A better value in one parameter does not by itself make a part suitable for an application: check the listed deviations against the design.
