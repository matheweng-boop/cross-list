How to read this
Application
One end system from the block-diagram library (e.g. an EV on-board charger, a Wi-Fi access point). The library has the applications listed on the Applications page; each is a block diagram built from public reference designs.
Needed in
How many of these applications have that function in their diagram. 29 of 56 = 29 diagrams contain it.
Door opener (portfolio anchor)
Of the applications that need the missing function, how many already contain at least one {{ co_label }} part elsewhere in the diagram. There we already talk to the designer, so a new product is easier to place. Open a row to see which of our functions they use.
Sockets (design-in positions)
Places on the board the function fills, summed over the applications. A diagram with two LDOs counts 2: one product could win both sockets.
Competition
How many established suppliers sell this function (public catalogues, indicative only, not market share). Hover to see them. A crowded market makes a new product harder to justify.
