What it is

The time from an input edge to the output edge. We compare the datasheet's typical value when it states one, else the maximum (owner, 22 Oct 2026); the source line of each value says which. It adds latency to control loops and protection paths and limits how fast a clocked interface such as SPI can run through the isolator.

When it deviates

A longer delay lowers the maximum SPI clock (the MISO data must make the round trip within half a clock period), adds loop delay and slows fault reaction. For gate drivers, the variation of the delay matters more than the delay itself.

Quick check: isolated SPI Engineering estimate

fSCLK ≤ 1 / (2·(2·tPD + tCO + tSU)), with the same part's maximum delay in both directions. Ignores skew and jitter.
