Matching rules

Priority groups per product family (edit rules/*.yaml). Hard parameters must match for FFF, Upgrade and Downgrade.

How the categories are decided
  • Same package – same body length, body width, lead span and pitch. The pin count may differ: a position without a pin counts as a no-connect.
  • FFF – same package and pinout, and every priority 1 parameter equal or better. If every priority 2 parameter is also equal or better it is FFF automatically; otherwise it needs review and an engineer accepts or rejects it.
  • Pin-to-pin – same package and pinout; function ignored.
  • Upgrade – no priority 1 parameter worse, at least one better; same or smaller package (same package only if the reference is package-locked).
  • Downgrade – at least one priority 1 parameter worse, same package; closest first.
  • Obsolete / NRND / last-time-buy candidates are always listed last.
