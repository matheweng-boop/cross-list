Cross rules

Priority groups per product family. Priority 1 must be equal or better for a functional match; priority 2 and 3 are shown for information and never block a cross. Hard parameters define what the part does.

How a cross type is decided
  • Same package – same body length, body width, lead span and pitch. The pin count may differ: a position without a pin counts as a no-connect. Pin-to-pin – same package and the same function on every pin.
{{ cross_type_definitions() }}

Preference: drop-in, then functional, then package equivalent. Anything else is not listed. Obsolete / NRND / last-time-buy candidates are always listed last.

Which datasheet value is compared
  • Typical first, then maximum (owner, 22 Oct 2026): performance values are compared at the datasheet's typical value when it states one; without a typical we use the maximum (for CMTI, which has no maximum, the minimum). This applies to propagation delay and CMTI today (gate drivers and digital isolators); each value's source line says "typ" or "max". Re-read so far: Skyworks Si82Ax-Fx, Si823x, Si8239x, Si826x, Si827x (CMTI), Si86 digital isolators, all Novosense gate drivers, Infineon 1ED314x. Other files still hold the maximum until they are re-read.
  • Limits stay limits: isolation rating and class, creepage, supply and temperature ranges and the UVLO option are ratings, not typical values, and are compared as stated.
  • UVLO: variants must match within 6 %. When none does, the next lower threshold ranks first: it starts up wherever the original does (why).
  • Dead time and overlap protection count as one capability, dead-time control (the difference).
