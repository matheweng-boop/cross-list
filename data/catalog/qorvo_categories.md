## Proposed new function ids

Most RF ids Qorvo needs **already exist** in the working-tree `data/blocks/functions.yaml` (power_amplifier, pa_module, rf_gain_block, filter_saw_baw, diplexer, rf_attenuator, rf_mixer, rf_synthesizer, rf_phase_shifter, rf_limiter, frequency_multiplier, rf_transceiver, rf_passive, antenna_tuner, beamformer_ic, wifi_fem, bt_fem, uwb_fem, v2x_fem, uwb_soc, wireless_soc, optical_tia, optical_driver, battery_charger, battery_monitor), so the YAML uses them. Only these two have no fitting id; the category column uses the existing functions.yaml categories:

| id | label | category | parts |
|---|---|---|---:|
| `catv_amplifier` | CATV / broadband-access amplifier (hybrid, push-pull, return path, fibre-node) | rf | 145 |
| `rf_power_transistor` | RF power transistor (discrete GaN / GaAs HEMT, die or packaged) | rf | 81 |

Notes on existing ids:

* `uwb_soc` is marked `source: external` in functions.yaml. Now that Qorvo is part of the combined company, the
  Qorvo DW3xxx / QM3xxxx UWB ICs and modules could make it a BizDev part.
* `amplifier` is the sensing (op-amp) block, so no Qorvo RF amplifier uses it.
* `rf_gain_block` also takes the VGAs and DVGAs (its label says "gain block / driver / VGA").
* `rf_synthesizer` also takes the VCOs.
* `rf_mixer` also takes I/Q modulators and demodulators.
* `rf_passive` takes the gain equalizers and power dividers.


Original ids that Qorvo fills: pmic, power_loss_protection, wide_vin_buck, pol_buck, buck_boost, cc_regulator, rf_pa_bias,
motor_controller, rf_switch, antenna_switch, lna, rf_frontend. The ids motor_controller, power_loss_protection, cc_regulator
and rf_pa_bias were proposed in the earlier research file and are now in functions.yaml.

## How function ids were assigned

* **The 82 verified parts** from `data/blocks/research/qorvo_parts.yaml` keep their ids. Variants with the same `base` inherit the
  verified id; this changed one part, ACT41000-101.E1T, to wide_vin_buck.
* **Store category → id** (first-pass rule id, then mapped onto the existing ids listed above):
  * Modular Power PMIC → pmic
  * Power Loss Protection → power_loss_protection
  * Intelligent Motor Controller → motor_controller
  * Battery Management → battery_charger (chargers, power banks, backup packs) or battery_monitor (PAC BMS SoCs)
  * RF Switch → rf_switch, or antenna_switch when the text says antenna (not antenna tuning)
  * CATV → catv_amplifier
  * TIA → optical_tia
  * RF Power Transistor → rf_power_transistor
  * any attenuator → rf_attenuator
  * Limiter → rf_limiter
  * Phase shifter → rf_phase_shifter
  * Mixer / RF Converter → rf_mixer
  * Modulator(-Demodulator) → rf_mixer
  * Frequency Multiplier → frequency_multiplier
  * VCO → rf_synthesizer
  * PLL → rf_synthesizer
  * RF Transceiver IC → rf_transceiver
  * Band-pass / notch / switch filter bank → filter_saw_baw
  * Duplexer / diplexer → diplexer
  * Power divider → rf_passive
  * Digitally tunable capacitor → antenna_tuner
  * UWB IC / module → uwb_soc
  * Smart Home Communications Controller → wireless_soc
  * Beamformer → beamformer_ic
  * Gain Equalizer → rf_passive
* **DC-DC categories:**
  * "buck-boost" → buck_boost
  * "bias" / "drain switch" → rf_pa_bias
  * "constant current regulator" → cc_regulator
  * otherwise wide_vin_buck if the text says "wide input" or any voltage above 18 V, else pol_buck
* **Amplifiers** (one store category of 525 rows), checked in this order:
  1. "low noise" / LNA → lna
  2. variable gain / DVGA → rf_gain_block
  3. power amplifier / PA / Power MMIC / die / pallet / W rating → power_amplifier, but cellular PA-duplexer / handset / PA-module parts → pa_module
  4. Gb/s / optical / modulator driver → optical_driver
  5. anything else → rf_gain_block

  Expect some misses at the edges: some driver amplifiers rated around 1 W land in power_amplifier, and some LNAs described only as
  "gain block" land in rf_gain_block.
* **Front-End Modules:** Wi-Fi / WLAN / 802.11, or a band inside 2.3–2.6 GHz or 4.9–7.2 GHz → wifi_fem;
  2.402–2.4835 GHz or Zigbee / BLE / 802.15.4 → bt_fem; UWB → uwb_fem; V2X / DSRC / 5.9 GHz → v2x_fem; cellular
  PA-duplexer → pa_module; the rest (X-band radar / T-R FEMs, base-station switch-LNA, sub-GHz AMR, unlabelled "FEM") → rf_frontend.
* **Rows with no store category** (7 rows from keyword pages): the id comes from the description.

## Gaps and caveats

* **qorvo.com is not reachable** (Vercel checkpoint), so:
  * there is no datasheet-grade data;
  * parts published only on qorvo.com are missing (the newest launches, and any automotive ACT/PAC variants not stocked by the store);
  * the selector parametrics are not available.

  370 parts have no datasheet link in the store. The other datasheet links point to qorvo.com and were not fetched.
* **The sitemap is from 2024-11-09.** The live listings add 1,056 newer ids. Removed categories hide some parts:
  * The listings for duplexers, power dividers, PLL modules, VCOs and DTCs now serve keyword-search pages.
  * Only their first, cached page (25 rows) was used. The parts there come with the store's own product-type label (86 parts
    added this way).
  * Rows on later pages of the duplexer (33 hits) and power-divider (34 hits) pages were not fetched. Robots disallows
    `/search/` and these pages behave like search, so they were not paged.
* **Discontinued parts:** 255 sitemap products that are no longer in a live listing were read from their own product pages.
  Most of them are Discontinued. Status is kept per part, so the app can filter.
* **Automotive is mostly null.** The store has no AEC-Q field. The value is true only where the description or features say
  AEC-Q or automotive. Qorvo's "Q"-suffix automotive switches and FEMs (e.g. QPC1217Q, QPF1002Q) are likely AEC-Q100 but are
  left null.
* **Spec values are catalogue values.**
  * Field names are verbatim from the store. Listing values have the unit in the field name (e.g. `Frequency Min (GHz)`).
  * Product-page values carry the unit in the value.
  * Some rows have only a description (`key_specs: {}`).
* **Missing functions.** No Qorvo parts were found for these functions in the store: supervisor, sequencer, voltage_reference,
  load_switch (except inside PMICs), isolated_dcdc, tvs_esd, digital_isolator, gate_driver, three_phase_gate_driver and
  half_bridge_driver (except inside PAC motor controllers), current_sensor, crystal_oscillator, clock_generator, clock_buffer,
  led_driver, audio_amp, multiphase, pol_ldo, ldo_tracker. Qorvo's catalogue has no standalone parts for these blocks; for
  BizDev the Skyworks side covers them.
* **SiC:** UnitedSiC FETs, JFETs, diodes and modules belong to onsemi (Jan 2025) and are omitted.
